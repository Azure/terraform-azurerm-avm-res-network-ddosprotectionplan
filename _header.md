# terraform-azurerm-avm-res-network-ddosprotectionplan

Module to enable DDoS protection plan in Azure

## Upgrading from AzureRM v3

AzureRM v4 is required. Set the root provider constraint to `~> 4.0` and configure its subscription ID through `subscription_id` or `ARM_SUBSCRIPTION_ID`. Module inputs, outputs, and resource addresses are unchanged.
